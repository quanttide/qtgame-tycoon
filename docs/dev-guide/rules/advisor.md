# 军师与老摊主

两个赔率贩子，不是「信息源 A / 信息源 B」，是两个不同的赌法。

## 两个赔率贩子

军师给区间：「今晚 140 ± 25」。帮你算该押几档——AI 的价值：给流程，给概率。每条建议标注信心来源：「模型推算」「我猜的」「有你的数据」。

- 盲信惩罚：按标注为「我猜的」建议执行而猜错时，亏损放大——玩家本可以自己去验证；
- 违抗奖励：持实测数据时可无视军师建议。雨天他劝你别出摊，你的数据显示这条街雨天只降一成——出了，赚了。

老摊主给点估计，还给语气：「今晚 185 上下，我拿二十年打保票」和「160 上下吧，我也说不好」——同一句话，两种分量。他比军师准的时候你不会知道，因为你没试过自己去拿那个数字。口头经验免费但有偏：老派口味、不信游客经济。

两个意见并排摆在押注按钮上方，差得远时页面直接说出来：「他俩差 60 签」——但绝不告诉你该信谁。要不要信一个说不出概率的人，是这个游戏里唯一没有正确答案的问题。

## 概率：把赔率摆到台面上

军师给区间，也给概率——两层：

- 主料层：今晚哪款主料更好卖。「蚝油串 30%、管坝 25%、卤鹅 45%」——几个数加起来是一百，玩家自己挑；
- 档位层：选定组合之后，押多少不亏。「押 160 五成半，押 120 七成八」——四个档四个把握。

两层都不给结论，只给分布。

- 给概率分布，不给结论。绝不出「今晚就该配卤鹅」这种话——那是答案，玩家点一下就完，课程当场死掉；
- 概率的准头挂在缺口上。军师只能拿他知道的因子算，实际开奖用的是全部因子：数据缺，他的概率就是猜的，会偏；你替他拿回来的数字越多，概率越准。「自己去现实里拿数字」第一次有了能感觉到的回报；
- 概率长在按钮上，不长在表格里：四档按钮各带一个「不亏的概率」，点之前就知道自己押的是多大的把握——这是赌桌规矩；
- 老摊主说不出概率。他给点估计和语气。他有时候比军师准，但你事后才知道——玩家面对的不是「谁更准」，而是「要不要信一个说不出概率的人」。
