# 核心循环

一天只有一件事发生：你押多少。

## 押注（早市）

决定今晚备多少签、备哪几样。备量四档：80 / 120 / 160 / 200；主料四选一、搭配四选一。

- 每一档当场扣原料钱；主料决定需求形状，搭配决定成本与毛利；
- 配两样不是第二件事：押 160 配卤鹅和押 160 配酿豆腐，是同一个动作的两种押法；
- 也可以选「今天不押」——去探店、去盲测、去重新探店。这一天没有营收，固定成本照扣。

## 开奖（晚市）

实际需求揭晓。

```text
需求 = 军师预测 × 天气 × 日历 × 客群 × 定价 × 抖动
```

- 备货 < 需求 → 断货，缺多少损失多少营收，老客复购掉；
- 备货 > 需求 → 剩货，损耗吃掉利润；
- 备货刚好 → 只有玩家能体会到的那个爽；
- 归因一句话：你信了哪条信号，它成没成。

出摊前可调一次定价滑杆（±30%）。价格带缺口未回填时，滑杆上没有参照，玩家在黑箱里调价；回填后，本地价格带区间直接标在滑杆上。

这就是唯一的玩法。不是「早市+行动卡」，也不是「备货+定价+事件」三件并列。是一件事：今晚，你押几档。
