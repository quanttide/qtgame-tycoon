# 玩法规则

玩家必须在不知道结果之前，先押上自己的钱。

今晚押多少、押什么，是唯一的赌注。选址、客群、菜单、组合、军师、老摊主、天气、日历、信号、缺口、误差条——全部是这张赌桌上的赔率提供者。没有任何系统能替玩家免掉押注。

## 核心原则

教学骨架一根不动，只把「拿数字」从按钮计时器变成玩法本身。

回填数字必须仍然比读信号更赚。信号能把「押 160 会不会亏」变成更有把握的判断，但不能变成答案——数据齐的玩家胜率要明显高于只读信号的玩家，否则课程被玩法吃掉。

整个游戏的成长曲线就是教学曲线：玩家从「信军师的数字」走到「自己拿数字、心里有数」。每一次实测，都对应玩家一个亲手做的经营决策。预测误差条仍是唯一的经验条，等级、技能树依然不需要。
