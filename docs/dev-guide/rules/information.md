# 信息与不确定性

## 信息的作用：只改赔率，不改赌局

探店、盲测、选址、客群、军师、老摊主——它们只有一个身份：让玩家押得更准。

- 探店 → 把军师预测的方差从 ±40% 压到 ±20%；
- 盲测 → 提高售价上限（同样的量，更多钱）；
- 选址 → 改需求基数与方差（老夜市走量方差小，广场夜市方差大但天花板高）；
- 客群结构 → 让天气/日历的乘数有具体形状（凤凰西路下雨只掉一成，吾悦广场下雨掉三成）；
- 军师 → 给区间和概率，不给答案；
- 老摊主 → 给点估计，不给区间；有时候比军师准，但事后才知道哪一次。

所有信息合起来，也只是把「押 160 会不会亏」变成一个更有把握的判断，不是一个确定解。

## 信号：会打架的信息

开摊前给 2–3 条。每条只给方向，不给数。

- 候选：次日天气、竞争摊位（隔壁今晚进了多少）、月底发工资、游客高峰、微信群热度；
- 关键在打架：同一晚至少给两条互相拉扯的。「月底发工资」（老客手头松）配「隔壁备足了货」（有人抢客）；「游客多」配「游客不认本地老口味」。玩家得自己判断哪条更重；
- 哪条更重必须每局变化。要是永远「游客多就配卤鹅」，两局之后玩家就总结出规律，又回到猜数字；
- 军师对每条信号的态度不一样：有的他能算（有你的数据），有的他只能猜。他说「我猜的」而你照着押、又猜错了，要重罚——那个数字你本来可以自己去拿。

## 执行误差：赌桌还在的证明

你押 160，实际需求 155，你不是刚刚好——你剩 5 签。你押 120，实际需求 158，你不是差一点——你断 38 签。

备货永远不可能刚好。这个 ±5–8% 的执行误差军师帮不上，是玩家自己的账。它让预测误差永远缩不到零，也让「数字对了、执行输了」成为真实结局而非文案。

这不是设计缺陷，是赌桌还在的证明。数据越全，预测越准；但下注那一刻手抖的那一下，谁也帮不了你。
