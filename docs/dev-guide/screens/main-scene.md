## 设计决定

- 押注是第一公民。四档按钮占据行动区全部宽度，金额写在按钮上，当场扣。玩家点下去之前就知道要花多少钱——这是赌桌规矩；
- 「今天不押」是次级按钮。视觉上小一号。选它才展开探店/盲测。押注才是默认动作，信息收集是替代方案；
- 军师给区间和概率，不给答案。「140±25」是四个数字，不是「120」；「卤鹅 45%」是分布，不是「今晚就配卤鹅」。玩家押的从来不是军师说的数，是他信军师信到什么程度；
- 概率两层，都长在动作上。主料层回答「哪款好卖」（几个数加起来一百），档位层回答「押多少不亏」，换主料四个概率一起重排——权衡是动手指，不是心算；
- 配两样和押多少是同一步。上排配主料与搭配（各四选一）、下排选档位，一次决定，不分两块面板；
- 摊主和军师并排站着，差得远时说出来。页面明说「他俩差 25 签」，但不暗示该信谁——信一个说不出概率的人，是玩家自己的账；
- 场景区承载全部反馈。签子堆高度 = 库存，客人数量 = 客流，对手摊剪影 = 竞争。玩家不读日志，他看摊；
- 归因三行写在同一页。押多少、需多少、剩多少——断货还是损耗，一眼看到，不用翻账本；
- 飘字不打断。「+137 签」从摊位飘出，客人散去，签子堆变矮。周日才用结算页。
