# 周结算页

每周日一次，一屏。误差条是主角，执行账第一次上台面。

```text
┌─────────────────────┐
│      第2周 · 结算     │
│                     │
│  军师周一预测: 110签/天│
│  实际:       118签/天 │
│  误差:      ±7%  ▓░░ │ ← 横向对比第1周
│  (第1周是 ±42%)       │    收窄 = 成长，一眼可见
│                     │
│  备货准确率: 82%      │ ← 执行账
│  断货次数:   1        │
│  信号命中:   2/3      │ ← 你信对了哪几条
│                     │
│  ”翻了台率你帮我拿到   │
│   后，我算得准多了“   │
│                     │
│  缺口: 还差 1 个       │
│       (底料成本)      │
│                     │
│    [ 进入第3周 ]      │
└─────────────────────┘
```

这页只有一个使命：让玩家看见误差条在一周周缩短，别的都是配角。
